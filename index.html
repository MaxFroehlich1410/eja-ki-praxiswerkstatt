Über diese Website

Ein Arbeitsblatt im Browser.

Die Website beschreibt die Workshopaufgaben. Jede Person bearbeitet die Aufgaben allein in einem KI-Tool und einem eigenen Dokument ihrer Wahl. Eure Ergebnisse werden hier nicht hochgeladen.

Häkchen der Checklisten werden ausschließlich in diesem Browser gespeichert. Es gibt keine gemeinsame Auswertung, kein Tracking und keine eingebetteten Fremddienste. Externe Links führen zu den jeweils genannten Anbietern; dort gelten deren Hinweise. Beim Hosting über GitHub Pages verarbeitet GitHub die technisch nötigen Verbindungsdaten.

Die Förderaufgabe ist eine Simulation. Der Originalantrag stammt von der BuntStiftung München; die Stiftung ist weder Veranstalterin noch Partnerin dieses Workshops. Alle Übungsdaten sind erfunden.
